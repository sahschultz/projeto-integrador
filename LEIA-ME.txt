# Energia Solar: Ciência e Sustentabilidade

Projeto Integrador CEP — 3º trimestre.

## Arquivos
- `index.html`: estrutura do site.
- `style.css`: estilos e layout responsivo.
- `script.js`: interações e simulador.

## Como usar
Extraia os três arquivos para a mesma pasta e abra `index.html` no navegador. Para publicar no GitHub Pages, envie os três arquivos para a raiz do repositório e ative GitHub Pages nas configurações do repositório.
